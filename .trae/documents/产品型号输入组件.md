# 产品型号输入+下拉选择组件

## 需求摘要

将展开详情面板中的产品型号输入框（第165行）改为输入+下拉选择功能。

## 接口信息

- **存储过程**: `WeiXin_zl_cpxl_select`
- **参数**: `@like` - 模糊搜索关键词
- **返回字段**: `V1` - 产品型号
- **Token**: 使用环境变量 `VITE_API_TOKEN`

## 当前状态

详情面板已有产品型号输入框（普通input），需改为搜索下拉组件：

```html
<!-- 当前代码（第165行） -->
<input type="text" v-model="item.productModel" placeholder="请输入" @blur="onProductModelBlur(item)">
```

## 实施计划

### 1. 修改 `src/api/index.js`

添加产品型号API：

```javascript
export const productApi = {
  getProductList: async (like = '') => {
    const result = await request('WeiXin_zl_cpxl_select', [
      { name: '@like', value: like }
    ])
    return result.data || []
  }
}
```

### 2. 修改 `src/components/ProcessCheck.vue`

#### 添加数据属性

```javascript
productList: [],              // 产品型号列表
showProductDropdown: false,   // 下拉显示状态
productTimer: null,           // 防抖定时器
currentProductItem: null      // 当前编辑的产品项
```

#### 修改模板（第164-166行）

将普通输入框改为搜索下拉：

```html
<div class="detail-row">
  <label><span class="required">*</span>产品型号：</label>
  <div class="search-select-wrapper" style="position: relative; flex: 1;">
    <input 
      type="text" 
      v-model="currentProductItem?.productModel" 
      placeholder="输入或选择产品型号"
      @input="onProductSearch"
      @focus="onProductFocus"
      @blur="onProductBlur"
    >
    <div v-if="showProductDropdown && productList.length > 0" class="search-dropdown" style="position: absolute; top: 100%; left: 0; right: 0; z-index: 1000; background: #fff; max-height: 200px; overflow-y: auto;">
      <div 
        v-for="p in productList" 
        :key="p.V1"
        class="search-dropdown-item"
        @mousedown.prevent="selectProduct(p)"
      >
        {{ p.V1 }}
      </div>
    </div>
  </div>
</div>
```

#### 修改展开方法

```javascript
async toggleExpand(id) {
  const item = this.processList.find(i => i.id === id)
  if (item) {
    item.expanded = !item.expanded
    if (item.expanded && !item.gybzLoaded) {
      await this.fetchGybz(item)
    }
    // 设置当前编辑项
    if (item.expanded) {
      this.currentProductItem = item
    }
  }
}
```

#### 添加方法

```javascript
async onProductSearch() {
  if (this.productTimer) clearTimeout(this.productTimer)
  this.productTimer = setTimeout(async () => {
    const model = this.currentProductItem?.productModel || ''
    await this.fetchProductList(model)
  }, 300)
},

async onProductFocus() {
  await this.fetchProductList('')
},

onProductBlur() {
  setTimeout(() => {
    this.showProductDropdown = false
  }, 200)
},

async fetchProductList(like) {
  try {
    const list = await productApi.getProductList(like)
    this.productList = list
    this.showProductDropdown = true
  } catch (e) {
    console.error('获取产品型号失败:', e)
  }
},

selectProduct(item) {
  if (this.currentProductItem) {
    this.currentProductItem.productModel = item.V1
  }
  this.showProductDropdown = false
  this.productList = []
}
```
