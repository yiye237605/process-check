# 修复产品型号输入关联信息清空逻辑

## 问题分析

当前逻辑：
- `onProductBlur` 只在输入值**不在列表中**时才清空字段
- 选择列表项后调用 `fetchGybz` 加载数据
- 问题：用户输入新值后，旧关联信息仍保留直到失焦

用户需求：
- 选择/输入任意产品时，**先清空旧关联信息**
- 再根据是否有数据决定显示空值还是加载的数据
- **提交按钮点击时不能触发清空逻辑**

## 解决方案

### 修改 `onProductBlur`

```javascript
onProductBlur() {
  setTimeout(() => {
    this.showProductDropdown = false
  }, 200)
}
```

### 修改 `selectProduct`

```javascript
selectProduct(p) {
  if (this.currentProductItem) {
    this.clearProductFields()
    this.currentProductItem.productModel = p.V1
    this.fetchGybz(this.currentProductItem)
  }
  this.showProductDropdown = false
  this.productList = []
}
```

### 修改 `onProductInput`

```javascript
onProductInput(e) {
  if (this.currentProductItem) {
    this.currentProductItem.productModel = e.target.value
  }
  this.onProductSearch()
}
```

## 关键改动

1. **选择列表项时**：先清空字段 → 再设置产品型号 → 再调用fetchGybz
2. **输入时**：只更新产品型号，不清空字段（用户可能在输入搜索）
3. **失焦时**：只关闭下拉列表，不清空字段

## 验证步骤

1. 选择列表中的产品 → 字段先清空再加载新数据
2. 输入自定义产品 → 字段保持，用户可手动填写
3. 点击提交 → 不会触发任何清空逻辑
