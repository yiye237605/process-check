# 添加标准要求输入框

## 需求

在"操作人"行后面添加"标准要求"输入框，显示V4字段值。

## 接口信息

- 使用现有 `fetchGybz` 接口（`WeiXin_zl_xjgx_gybz_select`）
- 返回字段 `V4` 显示在标准要求输入框

## 实施计划

### 1. 修改fetchGybz

```javascript
if (gybzData) {
  item.operator = gybzData.V3 || ''
  item.standardReq = gybzData.V4 || ''  // 新增
  item.standard1 = gybzData.V5 || ''
  // ...
} else {
  item.standardReq = ''  // 新增
  // ...
}
```

### 2. 模板

在"操作人"行后添加：

```html
<div class="detail-row">
  <label>标准要求：</label>
  <input type="text" v-model="item.standardReq" placeholder="请输入">
</div>
```

### 3. 修改fetchProcessList

添加 `standardReq: ''` 字段

## 验证步骤

1. 输入产品型号，失焦后V4自动显示在标准要求输入框
2. 可以手动编辑标准要求
