# 已提交状态持久化存储方案

## 需求

1. 提交状态持久化（localStorage存储）
2. 按时间段（上午/下午）自动重置
3. 上午（00:00-12:00）提交的显示已提交
4. 下午（12:00-24:00）提交的显示已提交
5. 进入下一个时间段后自动清空

## 当前状态

- `item.submitted` 存储在内存中（processList数组）
- 刷新页面后丢失
- 无时间段概念

## 解决方案

### 1. 数据结构

```javascript
// localStorage key: 'process-submitted-records'
{
  "55-am": 1717200000000,  // 工序ID-上午: 提交时间戳
  "55-pm": 1717232400000,  // 工序ID-下午: 提交时间戳
}
```

### 2. 时间段判断

```javascript
getTimePeriod() {
  const hour = new Date().getHours()
  return hour < 12 ? 'am' : 'pm'
}

isSubmittedToday(itemId) {
  const records = JSON.parse(localStorage.getItem('process-submitted-records') || '{}')
  const key = `${itemId}-${this.getTimePeriod()}`
  return !!records[key]
}
```

### 3. 提交时保存

```javascript
saveSubmittedRecord(itemId) {
  const records = JSON.parse(localStorage.getItem('process-submitted-records') || '{}')
  records[`${itemId}-${this.getTimePeriod()}`] = Date.now()
  localStorage.setItem('process-submitted-records', JSON.stringify(records))
}
```

### 4. 检查并清理过期记录（初始化时）

```javascript
cleanupExpiredRecords() {
  const records = JSON.parse(localStorage.getItem('process-submitted-records') || '{}')
  const currentPeriod = this.getTimePeriod()
  const newRecords = {}
  for (const [key, time] of Object.entries(records)) {
    const keyPeriod = key.split('-').pop()
    if (keyPeriod === currentPeriod) {
      newRecords[key] = time
    }
  }
  localStorage.setItem('process-submitted-records', JSON.stringify(newRecords))
}
```

## 修改文件

### `src/components/ProcessCheck.vue`

1. `created()` 调用 `cleanupExpiredRecords()`
2. `fetchProcessList()` 从localStorage读取submitted状态
3. `submitDetail()` 提交成功后调用 `saveSubmittedRecord()`
4. 删除 `item.submitted = true` 改为调用保存方法

## 验证步骤

1. 提交后刷新页面，已提交标志保持
2. 手动修改系统时间到12:00后刷新，标志清空
3. 重新提交，标志再次显示
